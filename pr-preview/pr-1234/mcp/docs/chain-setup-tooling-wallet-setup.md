# Wallet Setup

It's recommended to add Push Chain as custom network to your wallet before building your app on Push Chain. This will help you to test your app on Push Chain before deploying it on mainnet.

Not Required for Users

This is not a requirement for your users as they will connect to Push Chain using their wallet and through [UI Kit](/push-chain-website/pr-preview/pr-1234/docs/chain/ui-kit/) that will abstract away their wallet connection.

## Add Push Chain Specs to Wallet

Add the chain specs to your favorite EVM wallet under custom network. Some of the fields are optional depending on the wallet.

-   🍩 Donut Testnet
-   Mainnet - Coming Soon 🚀

| Field | Value |
| --- | --- |
| **Network Name** | `Push Chain Donut Testnet` |
| **RPC URL** | `https://evm.donut.rpc.push.org/` |
| **Chain ID** | `42101` |
| **Currency Symbol** | `PC` |
| **Block Explorer URL** | `https://donut.push.network` |
